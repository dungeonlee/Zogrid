Excel은 데이터는 기억하지만 "3열 창가 자리가 누구인지"는 기억하지 못합니다.
벽의 라벨은 자리를 표시하지만, 사람이 바뀔 때마다 다시 붙여야 합니다.

Zogrid는 이 두 가지를 하나로 합칩니다. 화면에 그린 그대로 벽에 배치되고, 좌석을 열면 사람과 장비가 그 안에 있습니다.
수백 대의 실습실, 한 층 전체의 사무실, PC방 좌석까지 한 장의 도면으로 관리합니다.

![방 배치](截图/room.png)

## 이런 곳에

**학교 컴퓨터실** — 수십~수백 대의 수업용 PC. 어느 자리에 어떤 모델, IP는 무엇인지, 어느 기계가 고장 나 비었는지 한눈에 보입니다.

**사무실 층** — 부서별 색 구분, 관리자 좌석 2칸 점유, 실제 좌석 번호와 일치. 사람이나 장비를 바꿀 때 칸 하나만 수정하면 됩니다.

**PC방 / 상주 운영** — 좌석 번호, 모델, 내외부 IP와 MAC을 한 화면에. 빈 좌석과 남은 대수는 하단에서 자동 집계됩니다.

## 주요 기능

### 1. 방은 원하는 대로

위 화면이 "방 속성" 패널입니다. 방 이름, 열과 행 수, 바닥색, 격자색을 여기서 정합니다.

- 방 개수 제한 없음, 이름도 자유롭게 (`3F-실습실A`, `2F-재무`, `PC방 1층`). 파일 하나로 건물 전체를 관리합니다
- 열·행 수 자유, 바닥과 격자 색도 변경 가능. 밝은 테마와 어두운 테마 모두 자연스럽습니다
- **방 배치 인쇄**: 시스템 프린터 사용, 흑백 선화, A4 세로, 자동 축소 후 가운데 정렬, 머리말에 모델 집계
- 방 잠금 가능. 배치는 고정되지만 좌석 내용은 편집할 수 있습니다

### 2. 좌석 모양은 직접 만든다

![블록 라이브러리](截图/library.png)

- 2인석, 3인석, 관리자석 포함 블록 기본 제공
- 직접 설계 가능: 행 × 열 자유, 한 칸 = 한 좌석. "관리자석 포함"을 선택하면 2칸을 차지합니다
- 블록마다 색을 지정해 부서나 구역을 구분합니다
- 라이브러리 안에서 위아래로 끌어 순서를 바꿀 수 있습니다

### 3. 원하는 곳에 놓는다

![드래그 배치](截图/layout.png)

- 라이브러리에서 방으로 끌면 격자에 자동 정렬됩니다. 좌표 입력이 필요 없습니다
- 벽 쪽, 가운데 통로, L자, 섬형 등 자유롭게 배치
- 우클릭으로 "위치 고정". 완성된 배치가 실수로 흐트러지지 않습니다

### 4. Ctrl을 누른 채 좌석을 끌기: 사람과 장비는 함께 이동하고 포트 번호는 벽에 남는다

좌석을 바꿀 때 가장 실수하기 쉬운 부분은 사람을 옮기는 일이 아니라 **포트 번호가 사람을 따라가느냐**입니다.

Zogrid의 규칙: **Ctrl을 누른 채 한 좌석을 다른 좌석으로 끌면 "사람 + 장비"가 통째로 교체되고, 포트 번호는 벽에 그대로 남습니다.**

| 함께 이동 (사람에 속함) | 그대로 남음 (벽에 속함) |
| --- | --- |
| 이름, 사번, PC 모델, 모니터 모델, IP, MAC, 비고 | 포트 번호 |

이렇게 나눈 이유: 포트 번호는 벽에서 나오는 케이블 위치입니다. 사람이 바뀌고 장비가 바뀌어도 그 구멍은 그대로입니다. 자리를 바꿀 때 랙에서 케이블을 다시 뽑을 필요도, 대장의 번호를 고칠 필요도 없습니다.

세부 사항:
- 관리자석, 일반석, 빈 좌석 사이에서 모두 끌 수 있습니다. 잘못 옮겼으면 되돌리면 됩니다
- 방이 잠겨 있어도 Ctrl 교체는 **그대로 동작합니다** (잠금은 배치만 고정)
- 교체 후 상태 표시줄에 "이름/모델/모니터/사번/IP/MAC은 함께 이동, 포트 번호는 원위치"라고 표시됩니다

### 5. 좌석마다 카드 한 장

![좌석 상세](截图/cell-edit.png)

- 이름, 포트 번호, PC 모델(한 좌석에 최대 4대), 모니터 모델(내선번호 기록용으로 쓰는 분도 많음), 사번
- "듀얼 네트워크"를 선택하면 한 좌석에 내부·외부 두 회선을 IP와 MAC까지 기록합니다
- 장비 상세(IP / MAC / 비고)는 편집과 읽기 전용을 전환할 수 있습니다. 확인 후에는 읽기 전용으로
- 좌석에는 핵심만 표시하고 세부 정보는 카드에 담습니다

### 6. 무엇이든 검색

![검색 강조](截图/search.png)

- 이름, IP, MAC, PC 모델, 사번, 포트 번호를 입력하면 즉시 검색
- 일치한 좌석이 분홍색으로 깜박여 바로 찾을 수 있습니다
- 검색·모델·유휴 강조는 **상호 배타**: 하나를 켜면 나머지는 꺼집니다
- Esc로 초기화

### 7. 전체를 한눈에

![장비 통계](截图/stats.png)

- 하단 실시간 집계: `모델 4종 · 9대 · 유휴 3대`
- 모델마다 카드가 있고 총수와 유휴 수가 표시됩니다
- **모델 클릭** 시 해당 모델 좌석이 모두 빛나고, **유휴 클릭** 시 "장비는 있고 사람은 없는" 좌석만 빛납니다
- 모델마다 글자색을 지정할 수 있어 좌석 안 글자와 대응됩니다

### 8. 표로 한 번에 채우기

![데이터 메뉴](截图/template.png)

- "데이터 → 빈 템플릿 다운로드": 이름 / 사번 / 내외부망 / MAC / IP / 비고(모델) / 포트 번호 / 모니터 모델의 8열
- **방을 만든 뒤 좌석에는 이름만** 입력하고 나머지는 표에 작성합니다
- "통합 문서 가져오기 → 좌석에 반영"으로 이름을 기준으로 IP·MAC·모델·포트 번호·모니터를 자동 입력
- 빈 셀은 방에서 이미 확인한 데이터를 덮어쓰지 않습니다
- "인원 목록 내보내기"로 같은 형식으로 되돌려 수정 후 다시 가져올 수 있습니다

## 그 밖에

- **7개 언어**: 简体中文, 繁體中文, 日本語, 한국어, English, Français, Deutsch. 툴바의 "언어"에서 전환하면 재시작 후 적용됩니다
- **열 이름도 언어에 맞춰**: 중국어 UI는 중국어 머리글, 그 외 언어는 영어 머리글. **두 형식 모두 가져올 수 있습니다**
- **완전 오프라인**: 네트워크·로그인·업로드 없음, 어떤 정보도 수집하지 않습니다
- **단일 exe**: USB에 넣어 다른 PC에서도 실행됩니다
- **데이터는 파일 하나**: `문서\Zogrid\zogrid.json`. 백업과 이전이 이 파일 하나로 끝납니다
- **다크 UI**: 서버실 조명에서도 눈이 편합니다
- **첫 실행 안내**: 설정이 없으면 라이브러리와 방 속성을 자동으로 열고 "새 방" 버튼이 점멸합니다

## 3단계로 시작

1. **방 만들기**: F2로 방 속성, 이름과 행·열 지정
2. **좌석 배치**: F1로 라이브러리, 블록을 끌어 벽과 같게 배치하고 이름 입력
3. **데이터 입력**: 데이터 → 빈 템플릿 다운로드 → 작성 → 가져오기 → 좌석에 반영
